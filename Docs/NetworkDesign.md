# 网络架构

项目使用一个 Dedicated Server 和两个远端客户端。服务器维护玩法规则，客户端提交所属玩家请求并展示复制结果。本地开发通过 Editor Server 启动相同的 DS 运行模式。

## 1. 规则、共享状态与表现分离

| 层次 | 入口 | 责任 |
| --- | --- | --- |
| 服务器规则 | GameMode | 目标登记、胜利门槛、玩家容量、重开校验 |
| 共享数据 | CoopGameState | 复制目标总数、完成数与胜利状态的结构化快照 |
| 玩家请求 | CoopPlayerController | 从所属连接调用服务器 RPC，交规则层复核 |
| 本地表现 | Presenter / Widget | 绑定状态事件、补读当前结果、创建当前客户端的 UI |

服务器状态写入集中经过 `ApplyAuthoritativeState`。通知基于本次状态转换，避免委托同步重入时重复广播胜利。晚绑定通过当前快照补读恢复 UI，不依赖历史一次性通知。

## 2. 机关协作与失败恢复

### 钥匙提交

拾取、安装和目标登记在服务器校验。插槽与 GameMode 分别约束自身提交和全局进度：只有钥匙操作成功才推进目标；拒绝或失败时保留原物品状态。同步提交使用局部重入保护，防止回调嵌套重复消费和计数。

### 人数与激活状态

占用组件负责不同玩家集合、多碰撞体重叠及 Pawn 生命周期，压力板负责自身激活，门负责合并多块板的协作条件。

人数变化与激活变化分开通知。例如一块板保持激活时新增第二名玩家，门仍需重新判断全局不同玩家数。销毁、失去控制与重新控制都走相同的占用刷新路径。

### 重开

客户端通过所属 Controller 请求重开。GameMode 检查世界、玩家与胜利状态，对首个有效请求去重；Travel 失败且旧世界仍有效时恢复请求状态，允许再次操作。

## 3. 按对象选择同步方式

| 对象 | 服务器 | 客户端 |
| --- | --- | --- |
| Character | CMC 移动处理与权威校验 | 复用 CMC 预测、校正、Saved Move 重放 |
| Key / Socket | 重叠、归位、消耗及登记 | 复制状态与 Actor 附着 |
| Plate / Gate | 判断激活条件并写入状态 | RepNotify 驱动本地表现 |
| MovingPlatform | Transporter 按预设轨道运动 | Actor Movement Replication |
| GameState | 保存规则结果 | 属性复制、委托通知和当前状态补读 |

属性复制用于传达当前结果；服务器 RPC 用于提交玩家请求。跨 Actor 的复制分别到达，因此玩法表现按当前可用状态收敛，而不是依赖几个对象在同一帧全部就绪。

### 静止机关

门和压力板处于静止状态时采用 `DORM_DormantAll`。服务器在改变复制属性之前刷新休眠，写入状态后请求网络更新。完成本地运动后停止对应 Tick，分别控制本地计算与网络复制检查的成本。

### 移动平台与角色

平台 Transform 和 LinearVelocity 由服务器生成，常规更新频率上限为 30 Hz。接收速度时更新组件速度，使 CMC 基座计算能读取平台运动信息。

角色复用引擎基座机制；跳离后保留相应惯性并进入自由空中运动。平台按关卡预设轨道运行，运动轨道和承载碰撞由关卡配置。诊断测试记录起跳、离开/落回基座、Move 时间戳与校正事件，用历史移动样本定位两端差异。

## 4. 连接生命周期

| 状态 | 行为 |
| --- | --- |
| Idle | 等待有效服务器地址 |
| Connecting | 地址归一化、发起 Travel，启动连接期限 |
| Connected | 本地控制器进入 PlayingState 后确认连接 |
| ReconnectWaiting | 根据配置等待下一次重试 |
| Reconnecting | 尝试恢复到原服务器的连接 |
| Leaving | 取消计时器和重连，回到连接菜单 |

连接期限为 20 秒，默认重连等待为 1 / 2 / 4 秒。拒绝重复请求不覆盖原连接地址。状态通知可能同步触发取消，因此内部状态先提交再广播，继续 Travel 前再次核对操作编号。

引擎全局网络失败事件按 World、GameInstance 和 NetDriver 归属过滤。某名玩家断线不关闭 DS，另一名玩家继续与服务器通信；重连后读取服务器保留的共享目标状态。

## 5. 配置与生命周期

`Content/Config/Gameplay.json` 在启动时加载，校验版本、字段类型、范围和文件大小。失败整表回退默认配置，避免混用新旧参数；Tick 不读磁盘。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| SessionMaxPlayers | 2 | DS 远端玩家容量，保留配置兼容字段名 |
| WinRequiredPlayers | 2 | 终点不同玩家数 |
| PlatformRequiredPlayers | 1 | 平台自身占用模式的激活人数 |
| PlatformMoveSpeed | 150 cm/s | 平台速度 |
| DoorMoveSpeed / PlateMoveSpeed | 250 / 80 cm/s | 门与压力板速度 |
| ReconnectDelaysSeconds | [1, 2, 4] | 有限重连等待间隔 |

外部委托与计时器在 EndPlay / Shutdown 对称清理。业务状态、连接流程、显示状态各自维护，UI 通过事件观察，不承担服务器规则。

验证方法见 [测试说明](../Tests/README.md)，性能数据见 [性能报告](Performance.md)。
