## 后续专项：移动平台与角色弱网同步

[阅读动态载人报告](PlatformRideSync.md)：围绕站立、行走、换向、起跳落回，记录问题复现、平台更新顺序与速度修复、空中惯性的取舍及验证边界。实验入口为显式 `RideMotion`，不包含在默认 `Scenario All` 中；命令与三种对照模式见 [测试说明](../../../Tests/README.md#移动平台与角色弱网同步ridemotion)。

最终 `PlatformInertia` 在 Normal/Moderate/Harsh 各 1 次通过，Normal 下 `Baseline` 与 `OrderedVelocity` 的 Jump 失败。Harsh Jump 仍有 13 次校正、最大可比较误差约 72.12 cm，不能表述为弱网已完全平滑。阶段数据来自双端 `motionMetrics`，每段约 4 秒；30 Hz 是配置上限，不是实测发送率。本专项使用复制关卡蓝图关键移动参数的 CMC 测试 Pawn，并非完整蓝图角色验收，也不以 CPU／带宽为本轮目标。

本专项公开证据位于 [PlatformRide](../../../Tests/Evidence/2026-09-27/PlatformRide)，与上面 15 例回归／42 轮性能的历史构建分开保存、分开解释，不能合并计数。

公开 JSON 是脱敏摘录；完整日志、原始报告和逐帧 CSV 保存在各报告标注的本地原始数据目录。原两篇报告和共用附录复盘先前构建的实测，后续动态载人新增结果以专项报告及其指纹为准，不向历史结果补写通过状态。
