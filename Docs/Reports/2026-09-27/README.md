# Co-op 网络实验与踩坑记录

初次整理：2026-09-27；后续实验补记至 2026-09-29。仅涉及本仓库双人 Co-op，不混入 FPS 项目的渲染、AI 或内存实验。

1. [实验总报告](NetworkExperimentReport.md)：42 组规模压测、15 例弱网回归、4 例短验收和后续动态载人专项，按问题、设计、结果、边界和下一步组织。三批构建与测试环境分开标注，不合并通过率或性能收益。
2. [数据附录](Appendix.md)：逐轮性能值、回归断言、动态载人逐阶段指标、失败对照、构建指纹与原始证据索引。公开 JSON 是脱敏摘录；未脱敏的本地原始包不要直接上传。
3. [项目踩坑报告](ProjectPitfalls.md)：按现象、根因、处理和验证记录真实故障，并把静态审计风险与运行复现区分开。

动态载人专项需显式运行 `RideMotion`，默认 `Scenario All` 不包含它；命令见[测试说明](../../../Tests/README.md#移动平台与角色弱网同步ridemotion)。[旧专项路径](PlatformRideSync.md)只作兼容入口，不再维护第二份实验正文。

后续定位见[Move 时间戳专项](PlatformMoveTimestampValidation.md)：含同 Move 双端状态证据与 2026-09-29 的 30/60 Hz 六轮对照；逐轮数据和复现命令在[附录 I](Appendix.md#i-平台频率与跳跃校正对照2026-09-29)。该对照未见提高频率的稳定收益，运动段同步仍是待验证候选。
