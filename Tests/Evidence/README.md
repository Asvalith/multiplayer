# 可展示测试证据

以下结果由 `ValidateProject.bat` 在两个本地 UnrealEditor 5.5 进程上生成。原始日志保留在忽略提交的 `Saved` 目录；同目录 JSON 是去除本机绝对路径后的结构化摘要。

## 完整项目流程

- `OnlineSubsystemNull` 当前地图 Session：创建、发现、解析地址和加入通过；没有自动切换地图。
- 服务器实际 Actor 流程：4 个钥匙/插槽、全部压力板、门、移动平台和双人胜利通过。
- 两端默认胜利 UI、服务器当前关卡重开、主机与客户端 Session 清理及返回菜单通过。
- 证据：[full-project-validation.json](full-project-validation.json)

## 弱网与自动重连

- 正常网络通过。
- 100ms 延迟、20ms 波动、2% 丢包通过。
- 200ms 延迟、50ms 波动、5% 丢包通过。
- 三组均由同一个客户端进程完成模拟断线后的自动重连。
- 证据：[weak-network-reconnect.json](weak-network-reconnect.json)

## 带宽 A/B

同一套双人玩法脚本、相同机关顺序下，读取服务器 `UNetDriver` 总发送字节：

| 配置 | 平台网络更新上限 | 流程平均发送速率 |
| --- | ---: | ---: |
| 对照组 | 100Hz | 6221.690 B/s |
| 当前配置 | 30Hz | 5437.045 B/s |

当前配置在本次受控样本中降低约 **12.61%**。该结果包含同一时间段内服务器的全部出站流量，不是只统计移动平台，也不代表公网或所有机器上的固定收益；它是一份可复现的参数选择依据。
