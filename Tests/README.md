# 项目验证

运行仓库根目录的 `ValidateProject.bat`，会自动启动本机 UE5.5 双实例并执行两组相互独立的回归：

1. 正常、100ms/2% 丢包、200ms/5% 丢包环境下的直连与自动短线重连；
2. `OnlineSubsystemNull` 创建/搜索/加入 Session，随后验证钥匙与插槽、压力板、门、移动平台、胜利区域、默认胜利 UI、当前关卡重开和双方退出。

第二组还会使用完全相同的确定性玩法流程做带宽 A/B：对照组把移动平台的网络更新上限设为 100Hz，项目配置保持 30Hz，并读取服务器 `UNetDriver::OutTotalBytes`。这个数据只用于证明当前频率选择在同场景下的效果，不冒充历史版本测试。

详细本地日志和原始报告生成在 `Saved/Logs`、`Saved/TestReports`，它们不提交 Git。去除绝对路径后的摘要会写入 `Tests/Evidence`，可随仓库直接展示。
